# AI Language Translator

## About
An AI-powered language translator that allows users to enter text,
select source and target languages, and receive translated text.

## Features
- Source language selection
- Target language selection
- Text translation
- Translation API integration
- Copy translated text
- Text-to-speech

## Technologies
- HTML
- CSS
- JavaScript
- Translation API

## How to Run
1. Clone the repository
2. Open the project folder
3. Configure the API if required
4. Open the application
